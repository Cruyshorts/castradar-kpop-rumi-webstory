CAST RADAR WEB STORY PACK
==========================

Story: Who Sings for Rumi? KPop Demon Hunters Voice Cast Explained

Files:
- index.html: AMP Web Story HTML.
- blogger-embed-post.html: Blogger post embed shell.
- assets/: 9:16 story images and Cast Radar logo.

How to use:
1. Host the entire folder on a public static host that supports HTML files, such as Netlify, Cloudflare Pages, GitHub Pages, or your own hosting.
2. Open the hosted index.html URL and test it on mobile.
3. Paste that hosted story URL into blogger-embed-post.html where it says PASTE-YOUR-PUBLISHED-WEB-STORY-URL-HERE.
4. Publish the Blogger post and link it from your KPop Demon Hunters articles.

Important:
- Blogger posts usually cannot publish a valid standalone AMP Web Story by themselves. Use Blogger as the embed/landing page and host the official story file on a static host.
- If your Web Story tool requires image URLs, upload the assets images there or to Blogger, then replace the local asset paths in index.html.
